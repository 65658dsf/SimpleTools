# PDF fallback font

`NotoSansSC-Regular.ttf` is the Simplified Chinese subset of Noto Sans SC used by
the native MuPDF CJK fallback hook.

- Source package: `@fontsource/noto-sans-sc@5.1.1`
- Source file: `files/noto-sans-sc-chinese-simplified-400-normal.woff2`
- Source SHA-256: `58bd23de339ac01fae909f65abe1cddc8f982a19399357c7158c14d4d1f501c7`
- Conversion: WOFF2 to TTF with FontTools; no glyph or table subsetting was performed.
- Bundled TTF SHA-256: `571fe79a95c4316fda67c5a230b83cd7834744a65b0e5abca267a66cfa69de83`
- License: SIL Open Font License 1.1 (`OFL-1.1.txt`)

The subset covers common Simplified Chinese characters and Latin text. It is not a
replacement for fonts embedded by a PDF and does not cover every CJK script or extension.
